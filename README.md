# 💻 Gigabyte Computers — Official Website

A modern and responsive web application for **Gigabyte Computers**, a local computer repair and electronics service shop.  
Built using **React + Tailwind CSS + Vite** for fast performance, clean design, and maintainable code.

---

## 🚀 Project Overview

Gigabyte Computers offers repair services and refurbished products for:

- Computers & Laptops
- Printers & Peripherals
- CCTV Cameras & Security Systems
- Audio Devices (Speakers, etc.)

The website aims to:

- Present services clearly and professionally
- Showcase refurbished items in a clean, filterable catalogue
- Enable instant contact via WhatsApp and quick quote forms
- Improve local discoverability (SEO + Google Maps integration)
